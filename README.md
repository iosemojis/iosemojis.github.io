## 🚀 Key Features

* **⚡ 1-Click Copy to Clipboard**: Instant copy for any Apple emoji character, Unicode code point (`U+XXXX`), HTML entity (`&#XXXX;`), or CSS escape (`\XXXX`).
* **📥 Multi-Resolution Image Exporter**: Generate and download transparent PNG assets at **16x16, 32x32, 64x64, 128x128, 256x256, and 512x512** resolutions directly in the browser via HTML5 Canvas.
* **🌐 Universal Cross-Platform Support**: Optimized for WhatsApp, Instagram, TikTok, Snapchat, Discord, iPhone (iOS), Android (Samsung, Xiaomi, Pixel), Windows, and Mac.
* **🔖 Dynamic Favicon Generator**: Copy ready-to-use SVG Data-URI `<link rel="icon">` tags using any emoji.
* **🔍 Instant AJAX Search**: Filter through 3,786 emojis in real-time by keyword, emotion, Unicode hex, or slang (e.g., *heart*, *cry*, *fire*, *apple*).
* **📖 Programmatic Meaning Guides**: In-depth semantic, psychological, and social media etiquette guides for every individual emoji.

## 📱 How to Get iPhone Emojis on Android (No Root)

Many users search for how to make Android emojis look like iOS emojis:
1. **Web Copy Method**: Visit [iosemojis.github.io](https://iosemojis.github.io/), tap any emoji to copy it, and paste directly into Instagram captions, WhatsApp chats, or TikTok bios.
2. **zFont 3 Font Switcher**: Download *zFont 3* from Google Play Store and apply the official Apple Color Emoji TTF font to your Android system font settings.
3. **iOS Keyboard Apps**: Install iOS-themed keyboard apps like *Green Apple Keyboard* for an authentic Apple typing experience on Android.

## 💡 How to Use Any Emoji as a Website Favicon

You can use any emoji as a high-resolution, vector SVG favicon with zero external image files. Simply add this snippet to your HTML `<head>`:

```html
<link rel="icon" href="data:image/svg+xml,<svg xmlns=%22http://www.w3.org/2000/svg%22 viewBox=%220 0 100 100%22><text y=%22.9em%22 font-size=%2290%22>🍎</text></svg>">
```
