Flags FAQs

How are country flag emojis created in Unicode? ▾

Each flag is composed of two Regional Indicator Symbol letters corresponding to its ISO 3166-1 alpha-2 country code (for example, 🇺 + 🇸 = 🇺🇸 United States).

Why do some flag emojis not display on Windows? ▾

Microsoft Windows does not include color artwork for national flag emojis, rendering them as two-letter country code boxes instead.
